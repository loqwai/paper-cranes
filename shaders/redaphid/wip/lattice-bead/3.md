# lattice-bead/3.frag — the onset fork

**Forked from** `2.frag` on **2026-09-04**, at `/vibej` iteration 9.
Music: an Eric Prydz set through the virtual mic (long progressive windups, ~125 BPM).
Body is a **byte-exact copy** of `2.frag` — only the header block differs. `2.frag` stays the
snapshot of the structure run; `3.frag` is the live surface from here on.

## Why fork here

Iteration 9 is the point where the shader's light stopped being driven by *measurements* and
started being driven by *events*. That is a different design, and it deserved its own file
before it gets tuned further.

The run had walked into the **shudder-vs-lag dilemma**: raw audio features shudder, and smoothing
them costs about a second of lag (measured at factor 0.10). Iteration 8 "fixed" the shutter by
moving the flare onto `energySpring` — which is not an escape, it is just sliding along the same
trade. `onsetEnvelope()` leaves the trade entirely: a second `AnalyserNode` with
`smoothingTimeConstant = 0` feeds an edge-triggered `onset` (true for exactly **one** frame), and
the shader synthesises its own attack/release instead of inheriting the audio's shape.

| drive | per-frame jitter | verdict |
|---|---|---|
| `energyZScore` (iter 5–7) | 0.3072 | the shutter |
| `energySpring` (iter 8) | 0.0320 | smooth, but ~1s late |
| `onsetEnvelope(0.012, 0.16)` (iter 9) | **0.0087** | 35× smoother than the z-score *and* low-latency |

| tempo source | implied BPM | note |
|---|---|---|
| `beat` | 280.0 | counting hats |
| `onset`, default refractory | 212.7 | still counting hats |
| `onset`, `?onset_refractory_ms=380` | **125.3** | median gap 479 ms, 3% spread — the actual tempo |

## Two params are not optional

- **`?wavelet=true`** — without it all seven wavelet springs read exactly `0.000`, so
  `bassLive` / `midsLive` / `trebLive` are dead and most of the shader is deaf. The synthetic
  bench *pins* these, so it is structurally blind to this failure and will never catch it.
- **`?onset_refractory_ms=380`** — at the default the detector free-runs at ~213 BPM chasing hats.

## The flare

```glsl
flareZ = onsetEnvelope(0.012, 0.16) * clamp(onsetStrength * 1.8, 0.0, 1.0) * QGATE * K179
```

Rides the **seed-grid rim only**. Light lane — never geometry, never the global multiplier.
It peaks around 0.35 during quiet passages because `QGATE` sits near its floor there; it reaches
full on loud material.

## Gotchas carried forward

- `manualFeatures.time` does **not** freeze the frame. `iTime` is `pinnedTime ?? performance.now()`
  and only the **`?time=` query param** sets it. Two verdicts were invalidated by this before it
  was caught (a control differed from itself by 44.6).
- The jam drawer registered `onset_refractory_ms` with `.min=0 .max=1`. Touching that slider
  collapses the refractory to sub-millisecond and the tempo lock is lost. Re-add `=380` if so.
- Magnitude-only reactivity metrics have **no sign** — one scored an *inverted* mapping
  (louder → darker) as highly reactive. Always correlate.
- Live correlation is noisy and passage-dependent. Do not tune on a single 8-second window;
  judge across a build *and* a drop.

## Standing channel hierarchy (from lattice-vj HANDOFF)

- Brightness **never** goes into the global multiplier.
- Geometry only **evolves** — per-frame *audio* on geometry is forbidden; a hand knob or a
  one-way eased step on a drop is fine.
- A ratchet needs a counter-ratchet in the same edit.
- Colour follows the slowest music; light and shading take all the audio.
- The seed grid is **lighting**, not geometry.
